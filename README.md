### Applications in AI and Machine Learning

Statistical concepts provide an important foundation for AI and
Machine Learning. They are used for:

- Understanding and summarizing datasets
- Feature analysis and covariance
- Dimensionality reduction such as PCA
- Distribution analysis
- Sampling and dataset construction
- Parameter estimation
- Model evaluation
- Quantifying uncertainty
- Parametric and non-parametric modelling
- Linear classification using hyperplanes

### Conclusion

Descriptive statistics helps summarize and understand observed data,
while frequentist statistics provides methods for making inferences
about populations from samples. Estimation, MSE, consistency, and
confidence intervals are important tools for statistical inference.
Parametric and non-parametric methods provide different approaches to
statistical modelling. Together, these concepts form an important
statistical foundation for AI and Machine Learning.
